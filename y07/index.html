Part C: IF and ELSE


IF checks a condition: a true or false question. When it's true, Python runs the lines under if. When it's false, it runs the lines under else.




Activity 6: What should I wear?


Type this in carefully, then run it.


temperature = 25
if temperature > 20:
    print("Wear a T-shirt")
else:
    print("Take a jumper")





The lines under if and else start with four spaces. Change temperature to 15: what happens?


Now write a password checker: if the password is "kiwi", print Welcome!, otherwise print Wrong password.





Need a hint?

To check whether two things are the same, Python uses two equals signs: ==. One equals sign stores a value.






Remember


An if line and an else line both end with a colon :. The lines under them are indented, so Python knows which lines belong to which.

Part D: FOR loops


A FOR loop repeats the indented lines. range(5) means "do it 5 times", and i counts each time round.


Activity 8: Loop it


Predict, then type and run each one.


for i in range(3):
    print("Hello")





for i in range(5):
    print(i)





for i in range(1, 6):
    print(i)






Why doesn't it reach 6?

range starts at the first number and stops just before the second number.




Now try a times table. Type it, run it, then change 7 to your own number.


for i in range(1, 11):
    print(i, "x 7 =", i * 7)







Challenge: finished early?


Make your times table print High! after any answer bigger than 50. You need an if inside the loop:


for i in range(1, 11):
    answer = i * 7
    print(i, "x 7 =", answer)
    if answer > 50:
        print("High!")





Now add an else that prints Low. Can you make it count down from 10 instead?
