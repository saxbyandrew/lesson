Testing input() on this page

This is a quick test. A small box will pop up asking you a question. Type your answer in it and press OK.

Activity 1: Say hello

name = input("What is your name? ")
print("Kia ora,", name)



Activity 2: Add two numbers


input() always gives back text. int() turns the text into a whole number so you can do maths with it.


a = int(input("First number? "))
b = int(input("Second number? "))
print("Total:", a + b)





Activity 3: Password check


guess = input("Password? ")
if guess == "kiwi":
    print("Welcome!")
else:
    print("Wrong password")
